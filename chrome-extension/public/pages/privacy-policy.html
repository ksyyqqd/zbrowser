隐私政策

最后更新日期：2026年9月2日

核心承诺：皮蛋浏览器助手（以下简称"本扩展"）采用纯本地运行架构，不设置任何服务器，不收集、不上传、不存储您的任何个人数据。所有数据处理均在您的本地浏览器中完成。

1. 我们收集哪些信息

1.1 本地存储的配置信息

本扩展会在您的浏览器本地存储以下配置信息，这些信息仅保存在您的设备上，绝不上传至任何服务器：

  • AI 模型配置：您选择的 LLM 提供商（如 OpenAI、Anthropic、Google 等）和模型名称
  • API 密钥：您输入的 API 密钥（使用 Chrome 本地存储加密保存）
  • 个人偏好设置：语言选择、主题设置、快捷键配置等
  • 任务历史记录（可选）：您执行过的自动化任务记录，用于历史回放功能
  • MCP 服务器配置：您配置的本地 MCP 服务器地址和工具列表
  • 自定义技能：您创建或导入的自动化技能模板
  • 工作流数据：您设计的可视化工作流定义

1.2 运行时的临时数据

在执行自动化任务时，本扩展会临时处理以下信息，这些数据仅存在于内存中，任务结束即清除：

  • 网页内容：当前标签页的 DOM 结构、文本内容（用于 AI 分析页面）
  • 网页截图：页面视觉快照（仅在启用视觉识别功能时）
  • 浏览器状态：当前 URL、标签页信息（用于导航和操作）

1.3 我们绝不收集的信息

本扩展不会收集以下任何信息：

  • ❌ 您的姓名、邮箱、手机号等个人身份信息
  • ❌ 您的完整浏览历史记录
  • ❌ 您的登录凭证、密码、Cookie
  • ❌ 您的信用卡或支付信息
  • ❌ 您的设备指纹或唯一标识符
  • ❌ 您访问网站的具体内容（除非用于当前任务）

2. 我们如何使用信息

2.1 本地处理

所有数据处理均在您的本地浏览器中进行：

  • AI 模型调用：使用您配置的 API 密钥直接调用第三方 AI 服务（OpenAI、Anthropic 等），本扩展不作为中间服务器
  • 页面分析：在本地解析网页 DOM 结构，识别可操作元素
  • 任务执行：根据 AI 决策在本地浏览器中执行点击、填写、导航等操作
  • 历史记录：任务历史仅保存在本地，用于您回顾和重放

2.2 第三方 AI 服务

当您使用本扩展调用 AI 模型时，您的网页内容会直接发送至您选择的 AI 服务提供商（非本扩展的服务器）。这些提供商包括但不限于：

  • OpenAI (GPT-4, GPT-4o 等) - 隐私政策
  • Anthropic (Claude 系列) - 隐私政策
  • Google (Gemini 系列) - 隐私政策
  • 其他您自行配置的 AI 服务提供商

重要提示：这些第三方服务有各自独立的隐私政策和数据处理规则。我们建议您在使用前仔细阅读其隐私政策。本扩展对第三方服务的数据处理行为不承担责任。

2.3 本地 AI 模型（完全离线）

如果您选择使用本地 AI 模型（如通过 Ollama 运行），所有数据处理将完全在您的本地设备上进行，不涉及任何网络传输。

3. 数据存储与安全

3.1 存储位置

  • 所有配置数据存储在 Chrome 浏览器的本地存储空间（chrome.storage.local）
  • API 密钥使用 Chrome 的安全存储机制加密保存
  • 任务历史存储在本地数据库（IndexedDB），您可随时清除
  • 无远程服务器：本扩展不设置任何云端服务器或数据库

3.2 数据安全措施

  • ✅ 敏感数据（如 API 密钥）加密存储
  • ✅ 所有网络请求均为 HTTPS 加密（直连 AI 服务商）
  • ✅ 不使用第三方分析工具或跟踪脚本
  • ✅ 符合 Chrome 扩展安全最佳实践

3.3 数据保留时间

  • 配置数据：永久保存在本地，直到您手动删除或卸载扩展
  • 任务历史：默认保留最近 100 条记录，您可在设置中调整或清除
  • 临时数据：任务结束后立即从内存中清除

4. 数据共享与披露

明确声明：我们不会与任何第三方共享、出售或披露您的数据。

唯一的"数据传输"场景是：

  • 您主动发起：当您使用 AI 功能时，网页内容会直接发送至您选择的 AI 服务提供商（这是实现功能的必要步骤）
  • 您完全可控：您可以选择使用本地 AI 模型（Ollama），实现完全离线运行

我们不会因以下原因共享数据：

  • ❌ 商业目的（广告、营销）
  • ❌ 数据分析或用户画像
  • ❌ 与其他公司的合作伙伴关系

5. 您的权利与控制

5.1 数据访问权

所有数据存储在您的本地浏览器中，您可以随时：

  • 在扩展设置中查看所有配置数据
  • 在任务历史页面查看历史记录
  • 使用 Chrome 开发者工具查看存储内容（chrome://extensions → 开发者模式 → 背景页）

5.2 数据删除权

您可以随时删除数据：

  • 清除 API 密钥：设置 → 模型配置 → 删除密钥
  • 清除任务历史：历史记录页面 → 清除全部历史
  • 清除所有数据：卸载扩展，所有本地数据将被永久删除
  • 或：Chrome 设置 → 隐私和安全 → 网站设置 → 查看所有网站的权限和数据存储 → 找到本扩展并清除数据

5.3 数据导出权

本扩展支持导出功能：

  • 导出自定义技能（JSON 格式）
  • 导出工作流配置（JSON 格式）
  • 导出任务历史（CSV 格式）

6. Cookies 和跟踪技术

本扩展不使用任何 Cookies 或跟踪技术：

  • ❌ 不使用 Google Analytics 或其他分析工具
  • ❌ 不使用广告跟踪像素
  • ❌ 不使用设备指纹识别技术
  • ❌ 不使用第三方 CDN 加载资源（所有资源内置于扩展中）

7. 儿童隐私保护

本扩展面向 13 岁及以上用户。我们不会有意收集 13 岁以下儿童的个人信息。如果您发现儿童向我们提供了个人信息，请通过下方联系方式告知我们，我们将立即删除相关信息。

8. 国际用户须知

本扩展在全球范围内可用。由于采用纯本地运行架构，不涉及跨境数据传输：

  • ✅ 符合 GDPR（欧盟通用数据保护条例）要求
  • ✅ 符合 CCPA（加州消费者隐私法案）要求
  • ✅ 符合中国《个人信息保护法》要求

唯一例外：如果您选择使用云端 AI 服务（如 OpenAI、Anthropic），数据会传输至这些服务商的服务器（可能位于美国或其他国家），请参考其隐私政策。

9. 隐私政策变更

我们可能会不定期更新本隐私政策。重大变更时，我们会：

  • 在扩展中显示通知
  • 在 GitHub 仓库发布更新日志
  • 更新本页面顶部的"最后更新日期"

继续使用本扩展即表示您接受更新后的隐私政策。

10. 联系我们

如果您对本隐私政策有任何疑问、意见或建议，请通过以下方式联系我们：

  • GitHub Issues：提交问题
  • 电子邮件：privacy@your-domain.com（请替换为实际邮箱）

我们将在收到您的请求后 30 天内回复。

Privacy Policy

Last Updated: September 2, 2026

Core Commitment: Pidan Browser Assistant (hereinafter "the Extension") uses a purely local architecture with no server infrastructure. We do not collect, upload, or store any of your personal data. All data processing occurs in your local browser.

1. What Information We Collect

1.1 Locally Stored Configuration Data

The Extension stores the following configuration data in your browser locally. This information is saved only on your device and is never uploaded to any server:

  • AI Model Configuration: Your chosen LLM provider (OpenAI, Anthropic, Google, etc.) and model names
  • API Keys: API keys you enter (encrypted and stored using Chrome's local storage)
  • Personal Preferences: Language selection, theme settings, keyboard shortcuts, etc.
  • Task History (optional): Records of automation tasks you've executed, used for history replay
  • MCP Server Configuration: Local MCP server addresses and tool lists you configure
  • Custom Skills: Automation skill templates you create or import
  • Workflow Data: Visual workflow definitions you design

1.2 Runtime Temporary Data

When executing automation tasks, the Extension temporarily processes the following information. This data exists only in memory and is cleared when tasks end:

  • Web Content: Current tab's DOM structure and text content (for AI page analysis)
  • Page Screenshots: Visual snapshots (only when vision recognition is enabled)
  • Browser State: Current URL and tab information (for navigation and operations)

1.3 What We Never Collect

The Extension does not collect any of the following:

  • ❌ Personal identification information (name, email, phone number)
  • ❌ Complete browsing history
  • ❌ Login credentials, passwords, cookies
  • ❌ Credit card or payment information
  • ❌ Device fingerprints or unique identifiers
  • ❌ Specific content of websites you visit (except for current tasks)

2. How We Use Information

2.1 Local Processing

All data processing occurs in your local browser:

  • AI Model Calls: Uses your configured API keys to directly call third-party AI services (OpenAI, Anthropic, etc.). The Extension does not act as an intermediary server
  • Page Analysis: Parses web page DOM structure locally to identify actionable elements
  • Task Execution: Executes clicks, fills, and navigation in your local browser based on AI decisions
  • History Recording: Task history is saved locally only for your review and replay

2.2 Third-Party AI Services

When you use the Extension to call AI models, your web content is sent directly to your chosen AI service provider (not our servers). These providers include but are not limited to:

  • OpenAI (GPT-4, GPT-4o, etc.) - Privacy Policy
  • Anthropic (Claude series) - Privacy Policy
  • Google (Gemini series) - Privacy Policy
  • Other AI service providers you configure

Important Notice: These third-party services have their own independent privacy policies and data processing rules. We recommend reading their privacy policies before use. The Extension is not responsible for third-party data processing practices.

2.3 Local AI Models (Completely Offline)

If you choose to use local AI models (e.g., via Ollama), all data processing occurs entirely on your local device with no network transmission.

3. Data Storage and Security

3.1 Storage Location

  • All configuration data is stored in Chrome's local storage (chrome.storage.local)
  • API Keys are encrypted using Chrome's secure storage mechanism
  • Task History is stored in local database (IndexedDB), which you can clear anytime
  • No Remote Servers: The Extension does not use any cloud servers or databases

3.2 Security Measures

  • ✅ Sensitive data (e.g., API keys) is encrypted in storage
  • ✅ All network requests use HTTPS encryption (direct connection to AI providers)
  • ✅ No third-party analytics or tracking scripts
  • ✅ Complies with Chrome Extension security best practices

3.3 Data Retention Period

  • Configuration Data: Permanently saved locally until you manually delete or uninstall the extension
  • Task History: Defaults to retaining the most recent 100 records; adjustable or clearable in settings
  • Temporary Data: Immediately cleared from memory after task completion

4. Data Sharing and Disclosure

Clear Statement: We do not share, sell, or disclose your data with any third parties.

The only "data transfer" scenario is:

  • User-Initiated: When you use AI features, web content is sent directly to your chosen AI service provider (necessary for functionality)
  • Fully Controllable: You can choose to use local AI models (Ollama) for completely offline operation

We will not share data for:

  • ❌ Commercial purposes (advertising, marketing)
  • ❌ Data analytics or user profiling
  • ❌ Partnerships with other companies

5. Your Rights and Controls

5.1 Right to Access

All data is stored in your local browser. You can always:

  • View all configuration data in extension settings
  • View history records on the task history page
  • Use Chrome DevTools to view stored content (chrome://extensions → Developer mode → Background page)

5.2 Right to Delete

You can delete data anytime:

  • Clear API Keys: Settings → Model Configuration → Delete Keys
  • Clear Task History: History Page → Clear All History
  • Clear All Data: Uninstall the extension; all local data will be permanently deleted
  • Or: Chrome Settings → Privacy and Security → Site Settings → View permissions and data stored across sites → Find extension and clear data

5.3 Right to Export

The Extension supports export functions:

  • Export custom skills (JSON format)
  • Export workflow configurations (JSON format)
  • Export task history (CSV format)

6. Cookies and Tracking Technologies

The Extension does not use any cookies or tracking technologies:

  • ❌ No Google Analytics or other analytics tools
  • ❌ No advertising tracking pixels
  • ❌ No device fingerprinting technologies
  • ❌ No third-party CDN for loading resources (all resources built into extension)

7. Children's Privacy Protection

The Extension is intended for users aged 13 and above. We do not knowingly collect personal information from children under 13. If you discover that a child has provided personal information to us, please contact us using the methods below, and we will immediately delete such information.

8. International Users Notice

The Extension is available globally. Due to its purely local architecture, no cross-border data transfers are involved:

  • ✅ Complies with GDPR (General Data Protection Regulation)
  • ✅ Complies with CCPA (California Consumer Privacy Act)
  • ✅ Complies with China's Personal Information Protection Law

Only Exception: If you choose cloud AI services (e.g., OpenAI, Anthropic), data will be transferred to these providers' servers (may be located in the US or other countries). Please refer to their privacy policies.

9. Privacy Policy Changes

We may update this Privacy Policy periodically. For significant changes, we will:

  • Display notifications in the extension
  • Publish update logs on GitHub repository
  • Update the "Last Updated" date at the top of this page

Continued use of the Extension indicates your acceptance of the updated Privacy Policy.
